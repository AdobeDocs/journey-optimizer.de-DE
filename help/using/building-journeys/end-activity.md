Mit der **[!UICONTROL Endaktivität]** können Sie das Ende jedes Pfades der Journey markieren. Sie ist nicht obligatorisch, wird aber aus Gründen der besseren optischen Übersichtlichkeit empfohlen. Wenn die Journey mehrere Endaktivitäten hat, empfehlen wir, jedem Ende ein Label hinzuzufügen, damit Berichte leichter verständlich sind. Weitere Informationen finden Sie auf [dieser Seite](../reports/live-report.md).

* **TL;DR:** Auf dieser Seite wird die Endaktivität in Journey Optimizer erläutert. Dies ist eine visuelle Markierung am Ende jedes Journey-Pfads, die optional ist, aber für die Lesbarkeit von Berichten empfohlen wird.

**intents:**

* Fügen Sie eine Ende -Aktivität hinzu, um den Abschluss eines Journey-Pfads zu markieren
* Kennzeichnen von Endaktivitäten zur Verbesserung der Lesbarkeit von Journey-Berichten
* Visuelles Unterscheiden mehrerer Journey-Pfade mithilfe von beschrifteten Endknoten

**Glossar:**

* **Endaktivität** Ein Journey-Knoten, der den Abschluss eines Journey-Pfads visuell markiert. Dies ist nicht obligatorisch, dient aber der *(produktspezifisch)*

**Leitplanken:**

* Die Aktivität Ende ist nicht obligatorisch. Journey funktionieren ohne sie.
* Es wird empfohlen, jeder Endaktivität einen Titel hinzuzufügen, wenn eine Journey mehrere Pfade hat, um die Interpretation von Live-Berichten zu vereinfachen.

**Terminologie:**

* Kanonischer Name: Ende Aktivität — Akronym: n/a — Varianten: Ende Knoten, Ende Tag
* Verwechseln Sie nicht: „Endaktivität“ ≠ „Endtag“ - das Endtag ist ein automatisch generierter Knoten, der beim Journey-Authoring sichtbar ist, während die Endaktivität eine platzierbare Komponente ist

**FAQ:**

* **F: Ist die Aktivität Ende erforderlich, um eine Journey zu veröffentlichen?** — Nein, sie ist nicht obligatorisch, wird aber aus Gründen der optischen Übersichtlichkeit empfohlen.
* **F: Warum sollte ich „Ende“-Aktivitäten kennzeichnen?** - Wenn eine Journey mehrere Pfade hat, helfen Beschriftungen, diese in Journey-Berichten zu unterscheiden.
* **F: Wo kann ich die Auswirkungen von End-Aktivitätsbeschriftungen sehen?** - Kennzeichnungen werden im Journey-Live-Bericht angezeigt, was die Verfolgung der Leistung auf Pfadebene erleichtert.
