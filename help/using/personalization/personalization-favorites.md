# Hinzufügen von Attributen zu Favoriten {#fav}

>[!BEGINSHADEBOX]

**Auf dieser Seite** Erfahren Sie, wie Sie Attribute in Ihrem Favoritenmenü hinzufügen, darauf zugreifen und sie entfernen können, um sie beim Erstellen von Personalisierungsausdrücken in Adobe Journey Optimizer schnell wiederzuverwenden.

>[!ENDSHADEBOX]

Durch das Hinzufügen verschiedener Attribute zum Favoritenmenü erhalten Sie schnellen Zugriff auf die am häufigsten verwendeten Elemente. Um ein Attribut zu Ihren Favoriten hinzuzufügen, klicken Sie auf das Menü mit den Auslassungspunkten und wählen Sie **[!UICONTROL Zu Favoriten hinzufügen]**.

<!--
![](assets/favorite-option.png)
-->

Um auf die von Ihnen favorisierten Elemente zuzugreifen, verwenden Sie das Menü **[!UICONTROL Favoriten]** im linken Bereich.

Aus dieser Liste können Sie das Personalisierungsobjekt schnell zu Ihrem aktuellen Ausdruck hinzufügen.

<!--
![](assets/favorite-list.png)
-->

Wenn Sie ein Element nicht mehr in Ihrer Favoritenliste sehen möchten, können Sie es aus den Favoriten entfernen.

<!--
![](assets/favorite-remove.png)
-->

**TL;DR**

Auf dieser Seite wird beschrieben, wie Sie häufig verwendete Attribute zum Favoritenmenü im Personalisierungseditor hinzufügen, zur schnellen Wiederverwendung darauf zugreifen und sie entfernen können, wenn sie nicht mehr benötigt werden.

**Intents**

* Hinzufügen eines Personalisierungsattributs zum Favoritenmenü für den Schnellzugriff
* Greifen Sie über das Menü Favoriten im linken Bereich des Editors auf die Favoriten zu
* Attribut aus der Favoritenliste entfernen

>[!TAB Glossar]

* **Favoritenmenü**: Ein dedizierter Abschnitt im linken Navigationsbereich des Personalisierungseditors, der schnellen Zugriff auf die Attribute bietet, die der Benutzer als Favoriten markiert hat, wodurch die Ausdruckserstellung beschleunigt werden kann. *(produktspezifisch)*

>[!TAB Terminologie]

* **Kanonischer Name:** Favoriten — Varianten: Favoritenmenü, Attributfavoriten, Favoritenattribute
* **Kanonischer Name:** Favoriten — Varianten: Favoritenmenü, Favoritenattribute

>[!TAB FAQs]

**F: Wie füge ich ein Attribut zu den Favoriten hinzu?**

Klicken Sie auf das Menü mit den Auslassungspunkten neben dem Attribut im Navigationsbereich und wählen Sie **Zu Favoriten hinzufügen**.

**F: Wo finde ich meine Lieblingsattribute?**

Im Menü **Favoriten** im linken Bereich des Personalisierungseditors.

**F: Wie entferne ich ein Attribut aus den Favoriten?**

Entfernen Sie das **aus** Favoriten im linken Bereich.
